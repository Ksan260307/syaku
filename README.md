# しゃくとりの森 — Inchworm Forest

小さな **しゃくとりむし** になって、虫の目から見た大きな世界をのんびり探検する、アニメ調の 3D オープンワールドゲームです。
戦闘はありません。体を「Ω」の字に曲げては伸ばす、本物そっくりの歩き方で、名所と「しずく」を探し、**65 種のいきもの**（と、めったに会えない **レア 7 種**）に会いに行きます。
PC・ゲームパッド・**スマホ／iPad** で、ブラウザから遊べます。

### ゲームのながれ

- 「はじめから」を選ぶと、はじめに **チュートリアル**（練習用の小さな森で、うごかし方をひとつずつ練習）をするか選べます。
- **しずく** を集め、**名所** を見つけます。しずくは、登った先や物のかげにかくれています。
- しゃくとりむしは **どんな面でも這って登れます**（キノコのかさ・切り株の壁・葉っぱの裏・いきものの背中も）。高い所では **糸** でぶら下がって下ります。
- いきものに近づくと **いきもの図鑑** に登録されます。もう一度会うと、しぐさを観察したり、**なかよし**（★1〜5）になれます。
- 集めた数で **きせかえ**（いろ・ぼうし・めがね 30 しゅ）が増えます。
- 見つけた名所へは、**地図から移動**（ファストトラベル）できます。進み具合と設定は、ブラウザに自動で保存されます。
- まだ行ったことがないエリアの名前は「？？？」になります（行くと名前がわかる）。

くわしくは [GUIDE.md](GUIDE.md) へ。

## 開発

- **エンジン**: Unity 6 (6000.5.4f1) / URP / UI Toolkit / Input System
- **モデル**: Blender 5.2 の Python スクリプトですべてプロシージャル生成（`blender/scripts/`）
- **音**: BGM・環境音・効果音も Python (numpy) で合成（`tools/make_audio.py`）
- **公開**: GitHub Actions → GitHub Pages（WebGL）

### フォルダ構成

```
blender/scripts/       Blender でモデルを生成するスクリプト（*.blend も出力）
blender/tests/         Blender のテスト
tools/                 アイコン・フォント・音の生成、ローカルビルドとテストのスクリプト
unity/                 Unity プロジェクト
  Assets/Art/Models    Blender から出力した FBX
  Assets/Scripts       ゲームのコード（Player / World / Gameplay / UI / Audio / FX）
  Assets/Shaders       トゥーンシェーダーなど
  Assets/UI            UI Toolkit (UXML/USS)・アイコン・フォント・図鑑の絵
  Assets/Editor        プロジェクトの自動セットアップとビルド
  Assets/Tests         EditMode / PlayMode のテスト
docs/                  ビルド済み WebGL（GitHub Pages の公開用）
.github/workflows/     GitHub Pages への自動デプロイ
```

### アセットを作り直す

```powershell
$blender = "C:\Program Files\Blender Foundation\Blender 5.2\blender.exe"
foreach ($s in "forest_kit", "creatures", "park_kit", "mountain_kit", "hut_kit", "wear_kit", "coast_kit", "shrine_kit", "night_kit", "xmas_kit") {
    & $blender -b --factory-startup --python "blender/scripts/build_$s.py"
}
python tools/make_icons.py
python tools/make_fonts.py   # ゲーム内のテキストを増やしたら、もう一度
python tools/make_audio.py   # python tools/make_audio.py night（xmas）で、夜の森（クリスマス村）の音だけ
```

### Unity で開く・ビルドする

- Unity Hub で `unity/` フォルダを開き、`Assets/Scenes/Forest.unity` を再生します。
  メニュー **Shakutori > Setup Project** でマテリアル・シーンを作り直せます。
- ローカルでビルドして `docs/` を更新：`powershell -ExecutionPolicy Bypass -File tools/build_webgl.ps1`
  （`-Assets` でモデル・音などの生成から、`-Setup` で Unity のセットアップからやり直す）
- タイトルのデモ映像（`unity/Assets/StreamingAssets/Demo/エリア.mp4`）は、PlayMode のテスト `DemoRecorder` で作ります（指定したときだけ動く［Explicit］）：
  `Unity.exe -batchmode -projectPath unity -runTests -testPlatform PlayMode -testFilter Shakutori.Tests.DemoRecorder`
  （`SHAKU_DEMO_STILLS=1` で場面ごとの絵だけ、`SHAKU_DEMO_AREAS=forest,park` でエリアをしぼる）

### テスト

```powershell
powershell -ExecutionPolicy Bypass -File tools/run_tests.ps1            # すべて
powershell -ExecutionPolicy Bypass -File tools/run_tests.ps1 -Only PlayMode
```

### 公開（CI/CD）

`main` に push すると `.github/workflows/deploy-pages.yml` が動き、GitHub Pages に公開されます。

1. リポジトリ設定 **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする（初回のみ）
2. そのままでも、リポジトリに入っているビルド済みの `docs/` が公開されます
3. GitHub Actions 上で Unity からビルドしたい場合は、**Settings → Secrets and variables → Actions** に次を登録します
   - `UNITY_LICENSE` … Unity Hub でライセンスを有効化したときにできる `Unity_lic.ulf` の中身（Windows: `C:\ProgramData\Unity\Unity_lic.ulf`）
   - `UNITY_EMAIL` / `UNITY_PASSWORD` … Unity アカウント（Pro ライセンスの場合は `UNITY_SERIAL` も）

   登録すると、push のたびに [game-ci/unity-builder](https://game.ci/) で WebGL をビルドして公開します。
4. ワークフローの権限は、ふだんは読むだけ（`contents: read`）。公開のジョブだけが `pages: write` / `id-token: write`、Unity のテストのジョブだけが `checks: write` を持ちます。
